# Chapter 1 — Repository Setup

## Goal

Set up a clean, professional foundation for the project before touching any cloud infrastructure: repository structure, licensing, and documentation conventions.

## Steps taken

1. Created a public GitHub repository (`build-your-own-rag-oci`)
2. Initialized with:
   - **README.md** — project overview
   - **.gitignore** — Python template
   - **LICENSE** — MIT License
3. Added `assets/` folder for static resources (logo, diagrams)
4. Wrote the full project README: features, architecture overview, prerequisites, chapter index, and a data disclaimer

## Design decisions

- **MIT License**: permissive, standard choice for educational/reference repositories
- **Fictional corpus only**: every document used later in this guide is invented for demonstration purposes — see [Corpus & Data Disclaimer](../README.md#corpus--data-disclaimer)
- **Chapter-based structure**: each phase of the build gets its own file under `docs/`, so the guide stays navigable as it grows
